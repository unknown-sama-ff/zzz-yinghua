## 已确认并修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 轮换任意访客 Cookie 可绕过匿名限流；过期身份桶长期留存 | 匿名请求按可信代理解析的 IP 计数；保留已验证微信身份；清理过期桶并限制身份总数。覆盖轮换/畸形 Cookie 和桶容量测试。 |
| 跨域重定向转发密钥、自定义敏感请求头或 POST 图片请求体 | GET/HEAD 跨域只保留公开请求头；其他方法跨域重定向直接拒绝。同源重定向仍可使用。 |
| URL 校验与实际连接间存在 DNS 变化窗口，IPv6 特殊地址过滤不足 | 在 TCP 连接使用的 DNS lookup 中再次验证所有结果，拒绝混合公网/内网结果、特殊地址和内嵌 URL 凭据。异步轮询 Worker 同样使用此传输层。 |
| 图片代理可返回含脚本的 SVG，直接访问时在本站来源执行 | 只允许 PNG/JPEG/WebP/GIF/AVIF/BMP/ICO 等位图 MIME，拒绝 SVG/XML 等活动文档；保留 `nosniff`。覆盖拒绝 SVG 与正常 PNG 返回测试。 |
| CORS 没有阻止不可信网页发起会改变状态的请求 | 解析请求体前拒绝不可信 Origin 的写请求；有独立签名校验的支付通知除外。原生客户端的无 Origin 请求继续支持。 |
| 元数据、支付通知和 multipart 字段资源边界不足 | 元数据 JSON 限 256 KB；含图片的生图、检测、图库与合成接口保留 50 MB；支付通知单独限 100 KB，并限定支付宝通知格式；上传限制文件/字段/part 数量。 |
| 小体积图片经极端比例缩放或异常缩略图参数可申请巨量合成画布 | 限制输入数量、尺寸、像素总量与缩略图尺寸，分配画布前校验。普通拼接与小程序大图片 JSON 路径有回归测试。 |
| 上游响应无统一体积上限，原始错误响应和签名 URL 进入日志 | 默认最多读取 96 MiB 解压后的响应，持续覆盖读取超时；不记录原始错误正文、视觉模型正文、URL 私有路径/查询参数。内容审核证据仍按原有脱敏逻辑返回。 |
| 直接公开上游任务编号，跨接口重号会串任务，顺序编号也容易猜测 | 为每次生成创建随机 UUID，内部映射上游编号并编码轮询路径；任务 JSON 禁止缓存。验证相同上游编号独立完成，以及真实 Worker 的本地轮询。 |
