# 影画查看器一键保存到画廊

日期：2026-10-26

查看器在 PNG 导出按钮旁增加「保存到画廊」，普通和全屏模式共用保存状态。缺少底图或可见图层尚未加载完成时不可保存；处理中防止重复提交，成功显示「已保存到画廊」，失败后仍可点击重试。改变图层组合、裁切、阴阳面图片或角色名后可保存新作品。

保存与 PNG 导出共用 `renderYinghuaComposite`。点击时固定当前图层、裁切与角色名，再合成为底图原始分辨率的图片；保存期间切换组合不会改变已提交作品，也不会把当前新组合错误标为已保存。仅输出作品画面，不包含按钮、边框或动效。

现有单图保存和查看器合成共用 `saveGalleryImage`，沿用 WebP 压缩、现有 `/api/gallery` 写入及本浏览器删除凭证。合成作品标记为「影画合成」，记录可见图层与实际六命阴阳面。成功后通知已打开的画廊刷新，并丢弃旧列表请求的过期结果；不调用生图接口，不修改后端或数据库结构。

## 验收

- `npm run lint`、`npm test`、`npm run build`。
- `node tests/browser/viewer-gallery-smoke.mjs`：使用已有 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定宿主模块路径、`BROWSER_EXECUTABLE` 指定浏览器、`STUDIO_SCREENSHOT_DIR` 指定截图目录；先启动 `npm run dev`。
- 本地 PNG 与上传 WebP 像素比对：900×600 原始尺寸保持一致，RGB 平均绝对误差约 0.46/255，来自既有 WebP 压缩。
- 浏览器验证双击只提交一次、保存期间切换组合、全屏共享状态、保存后画廊更新、删除凭证、失败重试、现有单图保存和图层加载失败时禁用。
- 使用触摸屏浏览器配置验证手机全屏保存与按钮可用。

浏览器中的五次画廊写入全部使用模拟响应，没有向公共画廊添加测试作品；未进行真实存储服务的写入联调。
