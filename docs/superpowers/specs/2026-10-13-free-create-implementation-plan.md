# 自由创作工作台 v1 实施与验证

2026-10-13；用户已批准工作台版本，并明确要求可折叠批量复用、失败重试和多会话同时生图。

1. 保留自由创作入口，将窗口展开为响应式工作台，桌面显示会话侧栏，手机使用会话切换条。普通聊天及下载、保存、放大入口继续复用。
2. 会话保存共享图片、批量模式、逐项素材与草稿。提供固定角色换画面和固定背景换角色；普通多参考图创作继续保留。
3. 每个已提交任务保存输入与请求的内存快照。增加排队、生成、成功、失败和结果未确认状态，使用尝试标识过滤迟到响应，原位重试不依赖当前草稿。
4. 用一个轻量调度器限制自由创作两个并发请求。生成中可以新建、复制和切换会话，批量每项独立提交与显示；限流或鉴权失败暂停待提交任务。
5. 共享 JSON Worker 增加请求关联及监听器清理；服务器正在运行的幂等记录不提前过期。普通网络重查使用原键，已确认失败重试使用新键。
6. 回归验证任务快照、乱序回写、双向批量输入顺序、失败补跑、上传归属和 Worker 并发。运行 lint、完整测试与构建，使用无费用的浏览器模拟请求检查桌面及窄屏操作。

本轮不做跨刷新持久保存与服务端取消，不新增第三方依赖。免费接口沿用当前额度规则，真实生图效果不能由模拟回归测试证明。
