# 影画工坊：暗色展厅首页与入口重组

日期：2026-10-26

## 已确认的设计

首页展示作品并提供创作入口，使用绝区零视觉语言：粗字标题、斜切标签、偏移画框与叠层角色作品。工作区保留现有生成操作，减少重复的玻璃、外发光与无关入口。

基础色为石墨黑 `#0E1015`、深灰面板 `#191D25`、正文白 `#F3F2EE`、次级灰 `#A6ADB9`；默认紫粉沿用既有品牌。中文采用 Microsoft YaHei / PingFang SC / Noto Sans CJK SC，英文字沿用自托管 Oswald。品牌配色、系统中文字体以用户确认的方案为准。

首页使用已有「作者推荐」WebP 素材，明确标注风格示例，点击调用现有图片放大预览。主按钮打开自由创作，次按钮进入角色工坊；手机端优先显示标题与操作，再显示作品。

## 页面和状态

Hash 导航提供首页、角色素材、影画创作、海报创作、画廊和提示词六个页面，不增加路由依赖。旧 `#prompt-gallery` 和 `#prompt-gallery-search` 链接继续有效；无效 Hash 回到首页。

各工作区首次访问后保留挂载，非当前区使用原生 `hidden`，从布局、焦点导航和图片编辑选择中排除。图库与提示词数据在对应页面首次打开时加载。切页取消当前图片选择，不取消生成任务，不清空草稿或参考图。刷新后的会话保存规则沿用原实现。

角色英文名移入角色素材。接口、模型、精细度、免费通道及特效集中到原生设置对话框；赞助入口在页脚。二维码在支持浮层内展开，避免弹到屏幕外；Escape 优先关闭赞助名单。

自由创作继续使用原有窗口、两槽队列、输入快照和重试机制；批量复用默认折叠。“找灵感”改为进入提示词页面，带入提示词时沿用已有的非空草稿替换确认。

## 主题同步

保留原 `Palette` 与取色算法，也保留生成提示词读取的原始色值。应用外壳统一调用 `applyTheme`；按钮文字和强调色从原色派生适当的对比度，不修改用于生成的配色数据。

每次上传和清除递增上传版本。异步取色仅能提交给发起时的上传版本，即使之后再次选择同一张图片也不会接受更早的结果。主上传、换装历史、三视图转主立绘以及编辑结果替换主立绘共用该机制。生成完成不再直接把捕获的旧主题写回 DOM。

## 验收与复现

静态检查：`npm run lint`、`npm test`、`npm run build`。

2026-10-26 本地结果：类型检查通过，116 项测试通过，生产构建成功。浏览器回归的十组场景通过，无运行时错误；另在生产服务器的 1440px 和 390px 视口验证了全部工作区及设置浮层的加载。

单元测试：`tests/frontend/studio.test.js` 检查页面映射、旧锚点兼容、不同明度配色的文字对比度、后完成的旧取色任务、清除上传和再次选择相同图片。

浏览器回归：先运行 `npm run dev`，再运行 `node tests/browser/studio-smoke.mjs`。使用可用的 Playwright；如果由宿主提供，设置 `PLAYWRIGHT_MODULE` 为其模块目录，`BROWSER_EXECUTABLE` 为浏览器可执行文件。`STUDIO_SCREENSHOT_DIR` 可选，用于保存截图。无需新增生产依赖。

浏览器脚本覆盖：

- 首页只使用本地素材，不请求图库、提示词或模型接口。
- 实际上传红、青绿、浅色与灰度 PNG；跨页保留角色、草稿与主题，清除后恢复默认色。
- 设置对话框焦点约束、Escape 关闭、关闭后焦点返回。
- 提示词带入、拒绝和接受替换、参考图保留、失败重试及切页期间后台完成。
- 图层查看器全屏和退出；隐藏工作区的图片不进入编辑选择。
- 支持浮层中的二维码及赞助名单关闭顺序。
- 320、390、768、1024 和 1440 像素视口布局。
- 旧提示词锚点、深链接刷新、浏览器返回和当前页导航回到顶部。
- 画廊失败时首页仍可用；特效偏好跨刷新保留，减少动态效果与模型精细度配置可用。

浏览器的生成、画廊、提示词和赞助接口使用模拟响应；生成验证不消耗真实模型额度。该验收验证 UI 与现有请求流程，不代表真实模型生成质量或公共图库网络联调结果。后端接口与数据库结构未改动。

仓库继续提交 `dist`，生产资源须在源代码最终修改后重新构建。
