# 零命衣装保真设计

**日期：** 2026-09-18

## 目标

零命生成必须保留模块 02 上传的角色三视图中的原始衣装设计，同时继续允许既有的姿势、镜头、光影和单色深色剪影表现变化。

## 范围

仅修改零命的提示词构造；不改动多图上传顺序、模型能力判断、风格样张处理、三命或六命流程。

## 设计

### 第一层：零命服装锁定优先前缀

在 `src/lib/prompts.ts` 新增中英文的 `ZERO_FATE_COSTUME_LOCK_PREFIX`，并由 `fillName()` 在 `styleId === 1` 时置于现有角色保真前缀与零命长模板之前。

该前缀将声明：

- 模块 02 上传的全彩三视图是衣装的唯一权威来源。
- 必须保留衣装款式、全部部件与内外层、领口和袖型、裙/裤长度、护甲、鞋袜、手套、配饰、图案、材质关系与固有配色。
- 禁止添加、删除、替换、合并、简化或重新设计任何衣装元素。
- 动作、镜头、明暗、材质表现和零命单色剪影渲染不得成为改变衣装设计的理由。
- 暂被手臂、头发或道具遮挡的衣物，在重新可见处仍须按三视图原设计恢复。
- 姿势、镜头、光影和单色深色剪影风格化仍可按照既有零命规则变化。

### 第二层：零命模板关键段落强化

在零命主模板中已有的服装、纹样与单色化描述附近，补充一句精简的结构不变规则。它只重申“单色化仅改变渲染，不改变任何衣装结构”，避免长提示中服装约束被动作或剪影指令稀释。

## 测试与验证

1. 运行 `npm test`、`npm run lint`、`npm run build` 与 `git diff --check`。
2. 以复杂分层服装、长外套/裙摆、护甲、袜装和多配饰角色生成零命，确认衣装部件、轮廓和固有关系不被改造；允许姿势、镜头、光影与单色剪影发生变化。
3. 确认三命和六命提示词及多图上传顺序没有变化。
