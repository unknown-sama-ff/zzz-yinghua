# 影画提示词优化、编辑替换与图层 PNG 导出设计

- 日期：2026-10-03
- 状态：实现完成；本地功能验证通过，真实生图效果待同条件 A/B 评估
- 范围：Web 前端提示词、04 影画动作设计编辑回写、05 影画查看器导出

## 1. 背景与目标

本次需求包含三项互相关联但可独立验证的改动：

1. 在不改变现有生成效果意图的前提下，简化并整理零命、三命、六命阳、六命阴的提示词。
2. 解决六命生成图中腿部结构高概率畸形的问题，但不得通过改变原提示词已经规定的视角、机位、透视、裁切、构图或动作来规避问题。
3. 将“继续修改”产生的当前编辑版本写回 04「影画动作设计」模块中对应的编辑前图片，并在 05「影画查看器」中按当前图层选择导出 PNG 合成图。

## 2. 已确认的产品决策

### 2.1 提示词原则

- 保留现有四种命格的核心画面语义、角色身份约束、输入图权威顺序、构图文字约束和生成流程。
- 优化方式采用语义去重、公共约束提取和结构重排，不采用机械删句。
- 不改变已经写好的视角、机位、透视、裁切范围、构图、角色位置、动作意图或文字位置。
- 六命阳和六命阴共用同一套结构稳定约束；仅增加人体结构修复规则，不加入任何会引导模型改变镜头或构图的描述。
- 六命结构约束的目标是：在原视角和原透视下，保持大腿、膝盖、小腿、脚踝和脚掌的连续关系；两条腿分别可辨；禁止额外肢体、重复关节、断裂、融合、异常弯折和不符合原透视的局部变形。

### 2.2 编辑替换行为

- “继续修改”生成新版本后，用户点击“替换 04 原图”时，只更新当前编辑所对应的 04 图片槽位。
- 不自动重新生成，不修改提示词，不重复扣费。
- 必须保留原目标的命格、阳/阴索引、图片类型和图层关联关系。
- 六命阳和六命阴只替换当前正在编辑的那一张，不影响另一张。
- 替换成功后，04 模块缩略图和 05 查看器对应图层立即使用新图片。
- 编辑窗口保持打开，允许用户继续迭代；替换成功需要有明确反馈。

### 2.3 05 导出行为

- 05 查看器增加“保存当前 PNG”操作。
- 导出的内容严格等于用户当前看到的图层合成结果。
- 只导出图层合成画布，不导出查看器按钮、边框、标题、网页或浏览器界面。
- 使用原始画布分辨率，不受浏览器窗口尺寸和缩放比例影响。
- 导出格式固定为 PNG。
- 图片未加载完成或没有可导出画面时，按钮不可用；导出失败时显示明确错误反馈。

## 3. 推荐实现方案

### 3.1 提示词重构

以 `src/lib/prompts.ts` 为主要修改点，保留对外导出的提示词和现有调用方式。将重复内容按以下层次整理：

1. 角色身份与参考图权威规则。
2. 当前命格的输入图顺序和编辑关系。
3. 必须锁定的视觉约束。
4. 命格特有的风格与服装/色彩处理。
5. 六命专用的人体结构稳定规则。
6. 负面限制和最终输出要求。

重构时必须确保最终送入生成 API 的语义不丢失。不得把相机、透视或画面布局改成新的方向；六命新增内容只能描述结构一致性和错误排除。

### 3.2 04 图片替换

沿用现有连续编辑会话中的目标元数据，将目标绑定到 04 的精确图片槽位。应用当前版本时：

1. 读取当前版本 URL 和目标的槽位信息。
2. 对当前目标进行版本/引用一致性检查，避免覆盖用户后来已经更新的结果。
3. 成功后写回 04 模块对应的图片状态。
4. 让 05 查看器从同一状态读取新图片，避免维护第二份脱节的图片副本。
5. 显示成功 toast；失败时保留编辑结果，不丢失当前会话。

按钮文案应从泛化的“应用当前版本”调整为面向用户动作的“替换 04 原图”，不可替换的预览图片仍应保持禁用并说明原因。

### 3.3 05 图层 PNG 合成

不使用浏览器截图方案。增加独立的客户端合成流程，复用查看器已有的图层顺序、定位、裁切、缩放和透明度规则：

1. 创建原始画布尺寸的 Canvas。
2. 按查看器当前有效图层顺序加载图片。
3. 依次绘制当前开启的图层；关闭的图层不绘制。
4. 对图片加载失败、跨域限制和空图层做可控处理，不让页面崩溃。
5. 调用 `toBlob('image/png')` 生成下载内容。
6. 通过浏览器下载 API 保存 PNG，并释放临时对象 URL。

导出按钮放在 05 查看器的操作区，状态应与当前图层选择同步。文件名使用稳定、可读的命名方式，并可包含命格/角色/时间信息，但不能影响导出内容。

## 5. 验收标准

### 提示词

- 四种命格仍能生成原有目标风格。
- 现有视角、机位、透视、裁切、构图、角色位置和文字位置的描述未被替换为新方向。
- 六命提示词包含结构修复规则，但不包含改变镜头或透视的规避规则。
- 公共重复内容减少，提示词仍可在现有界面中查看和编辑。

### 编辑替换

- 从 04 任意可替换图片打开“继续修改”。
- 生成并选中编辑版本后，点击“替换 04 原图”可以写回正确槽位。
- 六命阳/阴不会互相覆盖。
- 替换不会自动发起新的生成请求，也不会产生新的费用操作。
- 04 缩略图和 05 对应图层立即刷新。
- 预览类型图片不能误写回模块。

### PNG 导出

- 可以自由开关图层并看到对应合成结果。
- 点击“保存当前 PNG”后，下载文件为可打开的 PNG。
- PNG 只包含当前可见图层的合成结果，不包含网页控件。
- PNG 分辨率等于查看器原始画布分辨率，且不随浏览器缩放变糊。
- 未加载完成时按钮有明确禁用状态，失败时有可理解的反馈。

- 不通过改变视角、机位、透视、构图或裁切来回避六命腿部畸形。
