# 两阶段审核提示与双腿连接约束

用户要求保留两阶段默认，增加审核说明，并结合预览图的多余小腿分支问题强化结构约束。

## 线上核查

网站前端与 Railway 后端均已部署 108cfa4。健康检查与模型能力查询返回 200；已确认那次生图请求正常到达后端，约 38.8 秒后由上游返回 400 / sexual。该审核拒绝不是旧版本、静态资源缺失或接口不可达造成的。

## 本次改动

- 两阶段仍为默认，两种模式的请求准备与模型设置保持原样。
- 常驻说明：两阶段可能收到上游审核拒绝；若需要一步生成零命剪影，可主动选择直接生成。两种模式都受内容审核，不自动切换、不自动重发、不承诺直接模式一定通过。
- 中英文双腿约束共用一个片段，覆盖动作底稿、零命转绘、直接零命与六命：每条腿各有独立连接，每膝只能延续一条小腿，禁止在同一关节处分叉或重复补画鞋袜；保留遮挡、出框及原镜头与动作。
- 用户明确要求删除多余腿或修复分叉时，连续编辑提示词补充“先辨认并保留正确链、遵守指定保留分支、删除多余分支及其鞋袜、恢复背景”的规则。不固定删除画面左下或其他位置；普通编辑不加入修腿指令。

## 验证范围

136 项项目测试、类型检查、正式构建通过。9 项浏览器流程验证默认模式、可见提示、生成请求中的连接规则、编辑请求中的保留分支规则、失败后不自动切换及手机布局。

所有生图与编辑接口均被本地测试拦截。此验证证明网站发送了新约束，不能证明真实模型的畸形率或审核通过率改善，也没有消耗真实生图额度。
